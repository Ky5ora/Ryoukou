PROJECT ADMIN RYOKOU - PETUNJUK MENJALANKAN

1. Ekstrak ZIP ke folder kerja.
2. Buka folder Admin di VS Code.
3. Jalankan Admin/html/login.html menggunakan Live Server.
4. Masukkan email dan password demo apa saja yang valid.
5. Pada halaman OTP, gunakan kode demo 123456.
6. Setelah berhasil, halaman akan menuju Dashboard Admin.

NAVIGASI
- Pengaturan akun dibuka dari menu profil di pojok kanan atas, bukan dari sidebar.
- Pada halaman Pengaturan, admin dapat mengganti foto profil, nama lengkap, dan email.
- Halaman Pembayaran menyediakan pilihan Pembayaran Diterima atau Pembayaran Ditolak. Jika ditolak, pilih alasan atau tulis catatan.
- Tombol Lihat Gambar membuka modal bukti pembayaran; tombol Unduh Bukti Bayar mengunduh aset contoh.
- Invoice dapat dilihat dan dibagikan setelah pembayaran diterima.

FRAMEWORK DAN ASET
- UI memakai Bootstrap 5.3.3, Bootstrap Icons, CSS3, dan beberapa halaman dashboard lama masih mempertahankan utility Tailwind dari desain awal.
- Logo RYOKOU bersama berada di folder Admin/assets/ryokou-logo.png.

CATATAN PENTING
Proyek ini masih berupa frontend demo. Akun dan OTP belum diverifikasi ke server; kode OTP hanya simulasi 123456. Data pengaturan dan data invoice disimpan di localStorage browser. Pengiriman invoice via WhatsApp membuka pesan yang sudah disiapkan, tetapi admin tetap perlu menekan tombol Kirim. Untuk penggunaan nyata, sambungkan proyek ke backend dan database serta layanan email/OTP.
